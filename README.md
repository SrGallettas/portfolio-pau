# Portfolio de Pau

## Objetivo

Portfolio personal para buscar la primera oportunidad laboral como desarrollador web junior, con interes tanto en frontend como en backend.

## Direccion visual

- Identidad centrada en Pau; los proyectos no determinan la estetica del sitio.
- Blanco, negro y azul electrico, con pequenos acentos lima.
- Tipografia expresiva en titulos y legible en textos.
- Secciones abiertas, imagenes amplias y lineas finas.
- Movimiento breve, desplazamiento natural y soporte para movimiento reducido.
- Diseno adaptado a escritorio, movil y navegacion por teclado.

## Estructura prevista

1. Portada con nombre, perfil profesional y acceso a curriculum.
2. Pieza interactiva Interfaz / Logica, con entrada, validacion y resultado.
3. Proyectos con paginas individuales.
4. Sobre mi.
5. Contacto con correo, LinkedIn y GitHub.

## Tecnologia propuesta

Astro, TypeScript y CSS personalizado. JavaScript para interacciones concretas. Sin base de datos en la primera version.
